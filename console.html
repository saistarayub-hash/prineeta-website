Automation flow

How a visitor becomes a booking without you forwarding emails.

  1. Visitor → Form on /contact → writes to Inbox (preview: localStorage; live: POST + email).
  2. Inbox → Auto-reply sends Thanks — Prinita will reply in 24h and tags the enquiry new → read → booked.
  3. Booked → Calendar (owner sets link in Settings) — enquiry gets a booking link one-click.
  4. Instagram poll — daily pull from @prinita_kandasamy → Media queue → you tap Approve → Home hero updates.
  5. Vimeo save → Reels tabs update. No separate upload for each page.
  6. Press kit → one-sheet at /kit.html prints to PDF automatically — no manual layout.
